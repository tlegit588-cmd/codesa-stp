# CODEYSA-STP Website

Multi-page static website for travel, visa, relocation, business and investment enquiries in São Tomé & Príncipe.

Pages: `index.html`, `travel.html`, `investment.html`, `about.html`, `contact.html`.

Styles: `styles.css`; interactions: `app.js`; flyer images: `assets/`.

Cloudflare Pages: connect this GitHub repository, select the `main` branch, choose the None framework preset, leave the build command empty, and use the repository root as the output directory.

The contact form prepares a WhatsApp message. It does not save enquiries in a database or provide a staff dashboard. Visa approvals and investment returns are not guaranteed; verify all official requirements and conduct independent due diligence.
